# FrameGrade · AIGC视频质检评分框架

一个纯前端的AI生成视频结构化评测工具。把镜头语言、叙事逻辑、视觉一致性、技术缺陷四个维度拆解为具体评分项，用于统一标准、记录评测依据、生成可复用的结构化报告。

**[在线体验 →](#)**（部署到 GitHub Pages 后替换此链接）

## 这是什么，不是什么

**这不是一个自动视频分析工具。** 浏览器无法真正"看懂"视频内容，这个工具也没有调用任何视觉模型。

**这是一套评测方法论的落地实现。** AI生成内容质检最大的挑战不是技术，是标准不统一——不同人凭感觉打分，同样质量的内容可能得到完全不同的评价，结果没法用来指导内容筛选或模型迭代。这个工具把专业评测判断拆解成具体的、可重复执行的评分项，每一项对应明确的判断标准，而不是模糊的"好/不好"。

## 四个评测维度

- **镜头语言**：景别构图、镜头运动、景深虚实——影视专业训练的核心判断维度
- **叙事逻辑**：动作顺序、节奏匹配、内容完整度
- **视觉一致性**：主体一致性、色调光线连贯性、背景稳定性——AIGC视频最常见的问题集中在这里
- **技术缺陷**：肢体畸变、分辨率异常、水印等非预期内容

## 特点

- **纯前端，零依赖**：不使用任何框架，一个 HTML 文件即可运行
- **数据留在本地**：所有评测记录保存在浏览器 localStorage，不上传任何内容
- **标准化缺陷标签体系**：每个维度内置常见问题的受控词表（如"人脸漂移"“镜头抖动”），替代自由文本，保证多人评测口径一致
- **评测记录与统计看板**：所有评测自动积累为历史记录，支持按生成工具横向对比平均分、查看高频问题标签分布
- **结构化导出**：支持导出 Markdown 报告（团队协作/交付）、JSON（数据分析/标注管道对接）、CSV（Excel/表格分析）

## 两个视图

**评测页**：填写样本信息，对四个维度逐项打分并勾选问题标签，右侧实时生成评分报告。

**记录与统计页**：查看全部历史评测的汇总统计、不同生成工具的横向对比、高频问题标签排行，以及可排序、可删除、可导出的完整记录表。

## 维度设计依据

评测维度的设计来自我在影视内容创作中的专业判断——镜头语言和叙事逻辑是中国传媒大学戏剧影视导演专业的核心训练内容；视觉一致性和技术缺陷的识别标准，来自长期大量使用即梦、可灵进行AI视频生成的实践积累，这些也是AIGC视频评测、内容质检、数据标注类岗位实际工作中最常遇到的判断维度。
