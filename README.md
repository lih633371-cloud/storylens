# StoryLens · 叙事节奏诊断工具

一个纯前端的文本节奏分析工具。粘贴一段剧本、脚本、故事或文案，工具会分析句长变化、对话密度、结构分布，并给出结构层面的具体提示。

**[在线体验 →](#)**（部署到 GitHub Pages 后替换此链接）

## 这是什么

我在传媒内容创作和课程教学中，反复用到几个判断维度：句长的变化怎么制造阅读节奏、对话和叙述的比例怎么影响阅读体感、连续的长句或短句为什么会让读者疲劳。

这些原本是经验判断，靠"读起来顺不顺"的直觉来把握。这个工具把其中几个可以量化的维度做成了看得见的曲线——不是要替代人的判断，只是把"哪里可能有问题"从直觉变成了可以观察的东西。

## 特点

- **纯前端，无需后端**：所有分析在浏览器本地完成，不上传任何数据，不依赖任何 API
- **零依赖**：没有使用任何前端框架或第三方库，一个 HTML 文件即可运行
- **即开即用**：本地打开 `index.html` 或部署到任意静态网站托管即可使用

## 本地运行

直接用浏览器打开 `index.html`，或者：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 部署到 GitHub Pages

1. 将本仓库 push 到 GitHub
2. 进入仓库 Settings → Pages
3. Source 选择 `main` 分支，目录选择 `/ (root)`
4. 保存后等待几分钟，即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问

## 技术实现

- 句子切分：按中文句末标点（。！？）及换行符切分
- 对话识别：匹配中文引号包裹的内容
- 节奏曲线：Canvas 绘制逐句字数变化，含均值参考线
- 波动指数：句长的标准差，衡量长短句变化的丰富程度
